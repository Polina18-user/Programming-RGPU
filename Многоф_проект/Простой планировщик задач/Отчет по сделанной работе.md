# Отчет по проекту "Простой планировщик задач"
## Работа выполнена Федькиной Полиной Дмитриевной 1 курс ПОО
Проект создан на языке Си с использованием ресурсов VS code и Meson

<img width="1387" height="377" alt="image" src="https://github.com/user-attachments/assets/24536b9a-4610-48e5-8006-e700a87228b7" />

Пользовательский интерфейс.
Взаимодействие с пользователем происходит через вызов меню через программу "x64 Native Tools Command..." При помощи командной строки, которая приведена выше .\to_do_list.exe

<img width="767" height="281" alt="image" src="https://github.com/user-attachments/assets/7b22ef57-5aea-49e1-bbeb-0ade18592c31" />
1. Добавить задачу
2. Показать все задачи
3. Отметить задачу как сделанную
4. Удалить задачу
5. Сохранить задачу в файле (в данном случае в ZADACHI.cvs)
6. Прочитать задачи (в данном случае из файла Zadachnik.csv)
0. Выход
Задача пользователя выбрать то действие которое он хочет произвести

Возможные ошибки:
При скачивании данного проекта обратите особое внимание на ссылки на файл Zadachnik.csv. В строке должен быть указан полный адрес,  начиная от каталога c:\ иначе у программе могут возникнуть ошибки.
Еще одной особенностью это если вы хотите самостоятельно внести в файл Zadachi внести свои задачи, то очень внимательно нужно быть с пробелами и формой записью: все записывается без кавычек,
строчка не должна заканчиваться на пробел.
